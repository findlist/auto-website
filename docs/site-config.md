## 商业假设

- 当前候选：为高频工具用户提供赞助、付费定制、企业部署、批量处理或桌面版需求登记
- 状态：需求登记与价格验证已授权，支付等待真实商户配置
- 禁止事项：跨站追踪、设备指纹、广告画像、出售用户数据和模拟支付成功

## 隐私与表单决策

- Cookie：默认不使用，不展示无意义的 Cookie 横幅
- 跨站追踪：禁止
- 匿名统计：已授权，优先 Cloudflare Web Analytics
- 需求表单：第一方提交，收集邮箱、需求描述、使用场景和可选网站地址
- 明示同意：必选
- 数据保留：90 天，超期删除未转化线索
- 防滥用：频率限制、honeypot、服务端校验
- 敏感数据：禁止收集密码、Token、银行卡、身份证和支付账户信息

## 支付决策

- 模式：托管结账页或外部赞助平台
- 本站职责：展示方案、跳转托管页、记录匿名转化结果
- 本站禁止：采集或存储银行卡、支付密码和支付账户凭据
- 支付提供商：pending_user_account
- 赞助页 URL：pending_user_account
- 商户结账 URL：pending_user_account
- API 密钥：只能配置在服务端环境变量，不得写入仓库或客户端
- 未配置真实账号前：只开放需求登记，不显示虚假支付按钮
