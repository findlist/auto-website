## 具体修改内容

### 1. `src/pages/qr.astro` — 颜色选择器无障碍 & 跨浏览器一致性

#### 问题识别

通过对比 `qr.astro` 与 `color.astro` 的颜色选择器实现，发现三处不一致与缺陷：

| 维度 | `qr.astro`（修改前） | `color.astro`（基准） | 影响 |
| --- | --- | --- | --- |
| 桌面端尺寸 | 32×32px | 44×44px | 低于 WCAG 2.2 最小触控目标 44×44px |
| 移动端尺寸 | 40×40px | 44×44px（同桌面） | 低于 WCAG 2.2 最小触控目标 |
| 注释准确性 | 声称"符合 44x44"但实际 40×40 | 无误导注释 | 注释与实现不一致，误导后续维护 |
| Firefox 内部样式 | 缺失 `::-moz-color-swatch` | 完整 | Firefox 下色块无圆角裁剪，与 WebKit 视觉差异 |
| WebKit 内边距 | 2px | 4px | 32px 容器下视觉过紧，与基准不统一 |

#### 修改前

```css
/* 桌面端 */
.qrtool__color-picker {
  width: 32px;
  height: 32px;
  padding: 0;
  border: 1px solid var(--color-border);
  border-radius: var(--radius-sm);
  background: none;
  cursor: pointer;
}

.qrtool__color-picker::-webkit-color-swatch-wrapper {
  padding: 2px;
}

.qrtool__color-picker::-webkit-color-swatch {
  border: none;
  border-radius: 2px;
}
/* ❌ 缺少 ::-moz-color-swatch */

/* 移动端 @media (max-width: 768px) */
/* 移动端颜色选择器加大触控目标，符合 44x44 无障碍推荐最小尺寸 */
.qrtool__color-picker {
  width: 40px;   /* ❌ 注释声称 44x44，实际仅 40x40 */
  height: 40px;
}
```

#### 修改后

```css
/* 拾色器：44x44 触控目标，对齐 colortool 与 WCAG 2.2 最小尺寸推荐 */
.qrtool__color-picker {
  width: 44px;
  height: 44px;
  min-width: 44px;          /* 防止 flex 布局下被压缩 */
  padding: 0;
  border: 1px solid var(--color-border);
  border-radius: var(--radius-sm);
  background: none;
  cursor: pointer;
}

.qrtool__color-picker::-webkit-color-swatch-wrapper {
  padding: 4px;             /* 与 colortool 对齐 */
}

.qrtool__color-picker::-webkit-color-swatch {
  border: none;
  border-radius: 4px;       /* 与 colortool 对齐 */
}

/* Firefox 拾色器内部样式：与 WebKit 保持一致，避免跨浏览器视觉差异 */
.qrtool__color-picker::-moz-color-swatch {
  border: none;
  border-radius: 4px;
}

/* 移动端 @media (max-width: 768px) */
/* 颜色选择器已在桌面端统一为 44x44（WCAG 2.2 最小触控目标），移动端无需再放大 */
/* （移除了原先 40x40 的覆盖规则） */
```

#### 变更点汇总

1. **桌面端尺寸 32×32 → 44×44**：满足 WCAG 2.2 Success Criterion 2.5.8（Target Size — Minimum）44×44 CSS 像素推荐
2. **新增 `min-width: 44px`**：防止在 `inline-flex` 父容器（`.qrtool__color-item`）中被挤压
3. **WebKit swatch 内边距 2px → 4px**：与 `colortool` 视觉密度一致
4. **WebKit swatch 圆角 2px → 4px**：与 `colortool` 圆角令牌体系对齐
5. **新增 `::-moz-color-swatch` 规则**：补齐 Firefox 跨浏览器支持，消除 WebKit/Firefox 视觉差异
6. **移除移动端 40×40 覆盖**：桌面端已统一 44×44，移动端继承即可，减少冗余断点
7. **修正误导性注释**：原注释声称"符合 44x44"但实际 40x40，现已与实现一致

## 后续观察点（不在本次范围内）

以下是审查中识别但未在本次修复的潜在改进方向，供后续优化参考：

1. **超小屏断点一致性**：73 个工具页使用 `max-width: 414px`，但 `index.astro` 与 `qr.astro` 额外使用 `max-width: 375px` 作为第三级断点，`jwt-sign.astro` 使用 `max-width: 480px`。可考虑统一断点策略，但需逐页验证不影响布局
2. **preset 按钮风格收敛**：`anchor-positioning`、`contain`、`cron`、`dns`、`http-request`、`interpolate-size`、`ip` 等多个工具页各自实现 `.xxx__preset-btn` 样式，存在轻微视觉差异。可考虑在 `global.css` 抽取 `.preset-btn` 通用类，但属于较大重构
3. **`input[type='color']` 跨工具统一**：13 个 CSS 演示工具（background、box-shadow、border-radius 等）各自实现 `input[type='color']` 样式，可考虑统一，但 CSS 演示工具的视觉风格本应允许差异化
