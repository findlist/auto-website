# UI 优化记录 2026-07-31 (website)

## 修改文件

### src/components/AesTool.tsx — 错误提示 a11y 一致性

**问题**：加密结果（L439）与解密结果（L489）的错误提示 `<p className="aes__error">` 缺少 `role="alert"`，屏幕阅读器不会主动播报。全站 15+ 工具（Base64ImageTool、ColorTool、CronTool、ExifTool、HashTool 等）的错误容器均已添加 `role="alert"`，AesTool 是遗漏项。

**修改**：
- L439：`<p className="aes__error">` → `<p className="aes__error" role="alert">`
- L489：`<p className="aes__error">` → `<p className="aes__error" role="alert">`

### src/components/FindReplaceTool.tsx — 错误提示 a11y 一致性

**问题**：错误提示（L309）`<div className="fr__error">` 缺少 `role="alert"`，与同站其他工具不一致。

**修改**：
- L309：`<div className="fr__error">` → `<div className="fr__error" role="alert">`

### src/components/DnsTool.tsx — 同文件内错误提示 a11y 不一致

**问题**：L200 主查询失败错误容器 `<div className="dns__error">` 缺少 `role="alert"`，而同文件 L371 字段级错误 `<p className="dns__field-error" role="alert">` 已有。查询失败是比字段校验更严重的错误，屏幕阅读器却不会播报，属于同文件内 a11y 不一致。

**修改**：
- L200：`<div className="dns__error">` → `<div className="dns__error" role="alert">`

### src/components/Base64Tool.tsx — 错误提示 a11y 一致性

**问题**：L265 错误提示 `<div className="jsontool__error">` 缺少 `role="alert"`，屏幕阅读器不会主动播报。父容器 L263 已有 `role="status" aria-live="polite"`，但错误应立即播报（assertive）。全站 15+ 工具错误容器均已有 `role="alert"`。

**修改**：
- L265：`<div className="jsontool__error">` → `<div className="jsontool__error" role="alert">`
