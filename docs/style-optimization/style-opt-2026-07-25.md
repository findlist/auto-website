## 具体修改内容

### 1. `src/pages/index.astro` — `.blog-section__card` 缺失左侧主色指示条（视觉一致性）

#### 问题识别

首页"最新博客"模块的 `.blog-section__card` 在 hover 时使用了与 `.tool-card`、`.blog-card`（博客列表页）一致的主色光晕 + 上浮反馈，但**缺少** `.tool-card` 与 `.blog-card` 都有的左侧主色渐变指示条（`::before` 伪元素）。这导致用户在首页与博客列表页之间切换时，同样的卡片悬停反馈存在细微差异，破坏了全站卡片组件的视觉语言一致性。

对比：
- `.tool-card::before`（index.astro L1402-1413）：存在 ✅
- `.blog-card::before`（blog/[...page].astro L175-186）：存在 ✅
- `.blog-section__card::before`（修改前）：缺失 ❌

#### 修改前

```css
.blog-section__card {
  position: relative;
  border: 1px solid var(--color-border);
  /* ... */
  overflow: hidden;
  padding: 20px;
}

.blog-section__card:hover {
  border-color: var(--color-primary);
  box-shadow: var(--shadow-hover), 0 0 0 3px var(--color-primary-ring);
  transform: translateY(-4px);
}
/* 无 ::before 伪元素 */
```

#### 修改后

```css
.blog-section__card {
  position: relative;
  border: 1px solid var(--color-border);
  /* ... */
  overflow: hidden;
  padding: 20px;
}

/* 悬停时左侧出现主色指示条，与 .tool-card / .blog-card 视觉语言统一，
   形成全站卡片悬停反馈的一致识别符 */
.blog-section__card::before {
  content: '';
  position: absolute;
  left: 0;
  top: 0;
  bottom: 0;
  width: 3px;
  background: linear-gradient(180deg, var(--color-primary), var(--color-accent));
  transform: scaleY(0);
  transform-origin: top;
  transition: transform var(--transition-base);
}

.blog-section__card:hover {
  border-color: var(--color-primary);
  box-shadow: var(--shadow-hover), 0 0 0 3px var(--color-primary-ring);
  transform: translateY(-4px);
}

.blog-section__card:hover::before {
  transform: scaleY(1);
}
```

#### 配套修改：`src/styles/global.css`

在 `@media (hover: none)` 触摸设备重置块中，将 `.blog-section__card:hover::before` 加入 `transform: scaleY(0)` 重置列表，避免触摸设备上出现粘性指示条：

```css
.tool-card:hover::before,
.blog-card:hover::before,
.blog-section__card:hover::before {
  transform: scaleY(0);
}
```

### 2. `src/pages/index.astro` — `.tools__filter` 触摸目标过小 + 缺失焦点环（可访问性）

#### 问题识别

首页工具筛选按钮 `.tools__filter` 存在两个问题：

1. **触摸目标过小**：`.btn` 类有 `min-height: 36px`（global.css L439）保证触摸设备最小点击区域，但 `.tools__filter` 仅 `padding: 7px 14px` + `font-size: 13px`，实际高度约 27px，低于 WCAG 2.5.5 推荐的 44px 与项目内 `.btn` 的 36px 标准。

2. **缺失显式焦点环**：键盘 Tab 导航时，依赖全局 `:focus-visible`（global.css L689）的 `outline: 2px solid var(--color-primary); outline-offset: 2px`。但圆形按钮（`border-radius: 999px`）上的矩形 outline 视觉跳脱，与项目内 `.btn:focus-visible`（global.css L696-699）使用的 `box-shadow: var(--focus-ring)` 风格不一致。

#### 修改前

```css
.tools__filter {
  padding: 7px 14px;
  border: 1px solid var(--color-border);
  border-radius: 999px;
  /* ... */
  transition: border-color var(--transition-fast), color var(--transition-fast),
    background-color var(--transition-fast);
}

.tools__filter:hover {
  border-color: var(--color-primary);
  color: var(--color-primary);
}
/* 无 :focus-visible，无 min-height */
```

#### 修改后

```css
.tools__filter {
  padding: 7px 14px;
  /* 保证触摸设备上的最小点击区域，与 .btn 的 min-height: 36px 一致 */
  min-height: 36px;
  border: 1px solid var(--color-border);
  border-radius: 999px;
  /* ... */
  transition: border-color var(--transition-fast), color var(--transition-fast),
    background-color var(--transition-fast), box-shadow var(--transition-fast);
}

.tools__filter:hover {
  border-color: var(--color-primary);
  color: var(--color-primary);
}

/* 键盘焦点：与 .btn 一致的 box-shadow 焦点环，避免圆形按钮上 outline 视觉跳脱 */
.tools__filter:focus-visible {
  outline: none;
  box-shadow: var(--focus-ring);
}
```

### 3. `src/pages/index.astro` — `.tools__filter--active` hover 状态覆盖缺陷（激活态视觉）

#### 问题识别

激活态筛选按钮 `.tools__filter--active` 使用主色背景 + 白色文字。当用户 hover 激活态按钮时，`.tools__filter:hover`（特异性 0,1,1）会覆盖 `color: var(--color-primary)`，但 `background` 未被覆盖，保留主色背景。结果是：主色背景 + 主色文字 = 文字几乎不可见。

这与 2026-07-20 报告中修复的 `.difftool__view-btn--active` hover 不可读 Bug 同源。

#### 修改前

```css
.tools__filter:hover {           /* 特异性 (0,1,1) */
  border-color: var(--color-primary);
  color: var(--color-primary);   /* 覆盖激活态白字，主色文字+主色背景不可读 */
}

.tools__filter--active {         /* 特异性 (0,1,0) — color 被 hover 覆盖 */
  background: var(--color-primary);
  border-color: var(--color-primary);
  color: #fff;
}
```

#### 修改后

```css
/* 激活态 hover 时颜色加深，与 .btn--primary:hover 行为一致 */
.tools__filter--active:hover {   /* 特异性 (0,2,0) — 高于 .tools__filter:hover */
  background: var(--color-primary-hover);
  border-color: var(--color-primary-hover);
  color: #fff;
}

.tools__filter--active {
  background: var(--color-primary);
  border-color: var(--color-primary);
  color: #fff;
  box-shadow: 0 2px 6px var(--color-primary-ring);
}
```

### 4. `src/pages/index.astro` — `.tool-card--soon` 禁用态视觉提示不足（可用性）

#### 问题识别

未上线工具卡片 `.tool-card--soon` 内部链接使用 `aria-disabled="true"` 标记不可用状态，但视觉上仅通过 badge 颜色区分（灰色 vs 绿色）。用户可能误以为卡片可点击，尝试点击后无反应，造成困惑。

#### 修改前

```css
.tool-card--soon:hover {
  border-color: var(--color-border);
  transform: none;
  box-shadow: var(--shadow-sm);
}
/* 无 cursor / opacity 提示 */
```

#### 修改后

```css
/* 禁用态卡片：降低不透明度 + 禁用光标，明确传达"暂不可用"状态，
   与 aria-disabled="true" 语义对齐，避免用户误以为可点击 */
.tool-card--soon .tool-card__link[aria-disabled="true"] {
  cursor: not-allowed;
  opacity: 0.7;
}
```

### 5. 博客分页 + 标签云焦点环 + 激活态 hover 一致化（4 个文件）

#### 问题识别

博客列表页 `.pagination__page` / `.pagination__btn`、标签索引页 `.tag-item__link`、标签详情页 `.tag-cloud__item` 均存在两类问题：

1. **缺失显式焦点环**：依赖全局 `:focus-visible` 的 outline，与项目内 `.btn:focus-visible` 的 box-shadow 风格不一致。
2. **激活态 hover 覆盖缺陷**：`.pagination__page[aria-current='page']` 与 `.tag-cloud__item--active` 在 hover 时，背景色不会加深（对比 `.btn--primary:hover` 会加深为 `--color-primary-hover`），缺乏"激活态可交互"的反馈。

#### 修改前（以分页为例）

```css
.pagination__page:hover,
.pagination__btn:hover {
  border-color: var(--color-primary);
  background: var(--color-primary-soft);
}
/* 无 :focus-visible */
/* 无 [aria-current='page']:hover 加深 */
```

#### 修改后（以分页为例）

```css
.pagination__page:hover,
.pagination__btn:hover {
  border-color: var(--color-primary);
  background: var(--color-primary-soft);
}

/* 键盘焦点：与 .btn 一致的 box-shadow 焦点环，避免分页按钮在键盘导航时视觉跳脱 */
.pagination__page:focus-visible,
.pagination__btn:focus-visible:not(.pagination__btn--disabled) {
  outline: none;
  border-color: var(--color-primary);
  box-shadow: var(--focus-ring);
}

/* 当前页 hover 时颜色加深，与 .btn--primary:hover 行为一致 */
.pagination__page[aria-current='page']:hover {
  background: var(--color-primary-hover);
  border-color: var(--color-primary-hover);
  color: #fff;
}
```

同样的模式应用于：
- `src/pages/blog/tag/index.astro` — `.tag-item__link:focus-visible`
- `src/pages/blog/tag/[tag].astro` — `.tag-cloud__item:focus-visible` + `.tag-cloud__item--active:hover`

## 优化前后对比说明

### 优化前
- 首页"最新博客"卡片悬停时缺少左侧主色指示条，与博客列表页同类卡片视觉不一致
- 工具筛选按钮触摸目标仅 27px，低于 36px 标准，触摸设备易误触
- 工具筛选按钮键盘导航时使用矩形 outline，与全站 box-shadow 焦点环风格不统一
- 激活态筛选按钮 hover 时文字变主色，与主色背景对比度不足，几乎不可读
- 禁用工具卡片仅靠 badge 颜色区分，缺乏 cursor / opacity 提示，用户易误点击
- 博客分页与标签云键盘导航时焦点反馈不一致，激活态 hover 无颜色加深

### 优化后
- 首页"最新博客"卡片悬停时显示与 `.tool-card`、`.blog-card` 一致的左侧主色渐变指示条，全站卡片悬停反馈视觉语言完全统一
- 工具筛选按钮最小高度提升至 36px，触摸设备点击区域达标
- 工具筛选按钮键盘焦点使用 box-shadow 焦点环，与 `.btn` 风格一致
- 激活态筛选按钮 hover 时背景加深为 `--color-primary-hover`，保持白字可读性
- 禁用工具卡片增加 `cursor: not-allowed` + `opacity: 0.7`，视觉明确传达不可用状态
- 博客分页与标签云键盘焦点统一为 box-shadow 风格，激活态 hover 颜色加深，全站按钮交互反馈一致
