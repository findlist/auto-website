## 具体修改内容

### 1. `src/pages/diff.astro` — 视图切换按钮 active 态 hover 不可读 Bug（高优先级）

#### 问题识别

`.difftool__view-btn--active`（特异性 0,1,0）的 primary 背景会被 `.difftool__view-btn:hover`（特异性 0,2,0）覆盖为浅灰背景，但 `color: #fff` 保留，导致激活态按钮被悬停时呈现「白字浅底」几乎不可读。

对比 `json.astro` L258 与 `regex.astro` L176 都正确使用了 `:hover:not(.is-active)` 排除激活态，唯独 diff 遗漏。

#### 修改前

```css
.difftool__view-btn:hover {           /* 特异性 (0,2,0) — 覆盖 active */
  background: var(--color-bg-soft);
}

.difftool__view-btn--active {          /* 特异性 (0,1,0) — 被 hover 覆盖 */
  background: var(--color-primary);
  color: #fff;
}
```

#### 修改后

```css
/* :not(.difftool__view-btn--active) 排除激活态，
   避免 active 按钮被 hover 时丢失 primary 背景，导致白字浅底不可读 */
.difftool__view-btn:hover:not(.difftool__view-btn--active) {
  background: var(--color-bg-soft);
}

.difftool__view-btn--active {
  background: var(--color-primary);
  color: #fff;
}

/* 激活态按钮 hover 时颜色加深，与 .btn--primary:hover 行为一致 */
.difftool__view-btn--active:hover {
  background: var(--color-primary-hover);
}
```

#### 变更点汇总

1. **`hover` 选择器追加 `:not(.difftool__view-btn--active)`**：避免覆盖激活态背景
2. **新增 `.difftool__view-btn--active:hover` 规则**：激活态按钮悬停时颜色加深，与 `.btn--primary:hover` 行为一致

### 2. `src/pages/diff.astro` — toggle 组件样式补齐（低优先级）

#### 问题识别

`.difftool__toggle` 缺少 `user-select: none` 和 `input { margin: 0; cursor: pointer; }` 规则，与 `hashtool__toggle`（L122-135）、`pwtool__toggle`（L208-221）不一致。`DiffTool.tsx` L485-494 确认 `.difftool__toggle` 内含 `<input type="checkbox">`，无 `input { margin: 0 }` 会导致 checkbox 保留浏览器默认 margin，与 hashtool/pwtool 的 toggle 视觉对齐不一致。

#### 修改前

```css
.difftool__toggle {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  font-size: 13px;
  color: var(--color-text-soft);
  cursor: pointer;
  /* ❌ 缺少 user-select: none */
  /* ❌ 缺少 .difftool__toggle input { margin: 0; cursor: pointer; } */
}
```

#### 修改后

```css
/* 比较选项 toggle：与 hashtool__toggle / pwtool__toggle 保持一致 */
.difftool__toggle {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  font-size: 13px;
  color: var(--color-text-soft);
  cursor: pointer;
  user-select: none;       /* 防止点击 label 文字时选中文本 */
}

.difftool__toggle input {
  margin: 0;               /* 移除浏览器默认 margin，与同级 toggle 对齐 */
  cursor: pointer;
}
```

### 3. `src/pages/qr.astro` — 警告框颜色变量不一致（中优先级）

#### 问题识别

同一个 `.qrtool__warn` 警告框混用了两个不同的颜色变量：
- 文字色使用 `--color-warn`（#d97706 浅色 / #fbbf24 深色，深色模式有覆盖）
- 左边框色使用 `--color-warning`（#f5a623，**深色模式未覆盖**）

后果：
1. 同一警告框的文字色与左边框色不一致
2. 深色模式下 `--color-warning` 仍是 #f5a623，与深色背景下的其他 warn 元素（#fbbf24）不协调

#### 修改前

```css
.qrtool__warn {
  color: var(--color-warn);              /* 文字色 */
  background: var(--color-warn-soft);
  border-left: 3px solid var(--color-warning);  /* ❌ 另一个变量，深色模式未覆盖 */
}
```

#### 修改后

```css
/* 警告提示：边框统一使用 --color-warn，避免与文字色 --color-warning 不一致
   且 --color-warning 在深色模式未覆盖，导致暗色下边框色不协调 */
.qrtool__warn {
  color: var(--color-warn);
  background: var(--color-warn-soft);
  border-left: 3px solid var(--color-warn);  /* ✅ 与文字色、深色模式一致 */
}
```

### 4. `src/pages/qr.astro` — 删除冗余的深色模式覆盖（低优先级）

#### 问题识别

深色模式覆盖块中 `.qrtool__warn` 的覆盖完全等于浅色模式值，是无效的冗余代码：

```css
@media (prefers-color-scheme: dark) {
  .qrtool__warn {
    color: var(--color-warn);        /* ❌ 与浅色模式完全相同 */
    background: var(--color-warn-soft);  /* ❌ 与浅色模式完全相同 */
  }
  .qrtool__error {
    color: #fca5a5;                  /* ✅ 这个有实际覆盖 */
    background: var(--color-danger-soft);
  }
}
```

修复问题 3 后，`--color-warn` / `--color-warn-soft` 令牌已自动适配深色模式，无需在工具页重复声明。

#### 修改后

```css
/* 暗色模式适配：站点使用 prefers-color-scheme */
/* .qrtool__warn 已通过 --color-warn / --color-warn-soft 令牌自动适配深色模式，
   无需重复覆盖；仅 .qrtool__error 需要显式提亮文字色提升可读性 */
@media (prefers-color-scheme: dark) {
  .qrtool__error {
    color: #fca5a5;
    background: var(--color-danger-soft);
  }
}
```

### 5. 多个工具页 — 复制按钮补齐 `:active` 按压反馈（中优先级）

#### 问题识别

8 个核心工具页中，4 个工具页的复制按钮只有 `:hover` 反馈，缺少 `:active`（按下）反馈。而 `time-unit.astro` L320-322 已建立该模式：

```css
/* time-unit.astro 已有的规范写法 */
.tu__copy-btn:active {
  transform: translateY(1px);
}
```

按下时的轻微下沉反馈能让用户明确感知"点击已生效"，对复制按钮这类无页面跳转的即时操作尤其重要。

#### 涉及文件与修改

| 文件 | 选择器 | 修改 |
| --- | --- | --- |
| `src/pages/json.astro` L398-401 | `.jsontool__tree-copy` | 新增 `:active { transform: translateY(1px); }` |
| `src/pages/jwt.astro` L510-513 | `.jwttool__copy-btn` | 新增 `:active { transform: translateY(1px); }` |
| `src/pages/color.astro` L375-378 | `.colortool__copy-btn` | 新增 `:active { transform: translateY(1px); }` |

未修改的工具页：
- `hash.astro`、`qr.astro`、`password.astro`、`diff.astro`、`regex.astro` 均使用全局 `.btn` 类，已由 `global.css` L448-452 的 `.btn:active { transform: scale(0.97); }` 提供按压反馈

#### 新增代码示例（json.astro）

```css
.jsontool__tree-copy:hover {
  color: var(--color-primary);
  background: var(--color-bg);
}

/* 按下时轻微下沉，给用户即时操作反馈（与 tu__copy-btn:active 模式一致） */
.jsontool__tree-copy:active {
  transform: translateY(1px);
}
```
