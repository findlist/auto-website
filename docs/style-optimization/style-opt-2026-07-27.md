## 三、具体修改内容

### 3.1 修复 QrTool 类名 bug（`src/components/QrTool.tsx`）

**问题**：QrTool 组件中"实时生成"开关与"容错等级"下拉框错误地使用了 `uuidtool__` 前缀的类名，而 `uuidtool__toggle` / `uuidtool__select` 仅在 `uuid.astro` 中定义，导致 QR 工具页面这两个表单元素无样式渲染。

**修改点**：

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| 实时生成开关 `<label>` | `className="uuidtool__toggle"` | `className="qrtool__toggle"` |
| 容错等级 `<select>` | `className="uuidtool__select"` | `className="qrtool__select"` |

### 3.2 补全 qr.astro 缺失样式（`src/pages/qr.astro`）

**问题**：`qr.astro` 的 `<style is:global>` 块中未定义 `.qrtool__toggle`、`.qrtool__toggle input`、`.qrtool__select` 三条规则，导致即使类名修复后元素仍无样式。

**新增样式**：

```css
/* 实时生成开关：与 uuidtool/pwtool 保持一致的风格 */
.qrtool__toggle {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  font-size: 13px;
  color: var(--color-text-soft);
  cursor: pointer;
  user-select: none;
}

.qrtool__toggle input {
  margin: 0;
  cursor: pointer;
}

/* 容错等级下拉框：与 uuidtool/pwtool 统一表单元素风格 */
.qrtool__select {
  padding: 4px 8px;
  font-size: 13px;
  border: 1px solid var(--color-border);
  border-radius: var(--radius-sm);
  background: var(--color-bg);
  color: var(--color-text);
  cursor: pointer;
  transition: border-color var(--transition-fast), box-shadow var(--transition-fast);
}

.qrtool__select:hover {
  border-color: var(--color-primary);
}

.qrtool__select:focus-visible {
  outline: none;
  border-color: var(--color-primary);
  box-shadow: 0 0 0 3px var(--color-primary-soft);
}
```

**设计要点**：
- `.qrtool__toggle` / `.qrtool__select` 基础属性完全复用 `uuidtool__` 与 `pwtool__` 的定义，保证三个工具页的表单元素视觉完全一致
- `.qrtool__select` 额外补充 `hover` 与 `focus-visible` 交互态，提升键盘可达性与可供性提示（这是 `uuidtool__select` / `pwtool__select` 未覆盖的细节，本轮在 QR 工具上先行增强）
- 所有颜色、圆角、过渡均引用 `global.css` 中的设计令牌（`--color-primary`、`--color-primary-soft`、`--radius-sm`、`--transition-fast`、`--ease-out`），暗色模式通过令牌自动覆盖，无需额外适配

## 四、优化前后对比说明

### 4.1 QrTool 实时生成开关

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 类名 | `uuidtool__toggle`（未在 qr.astro 定义） | `qrtool__toggle`（已定义） |
| 渲染效果 | 复选框与文字无间距、无对齐、无指针手型 | inline-flex 居中对齐，6px 间距，pointer 手型，user-select 禁用 |
| 一致性 | 与同页其他 `qrtool__*` 元素割裂 | 与 uuid/password 工具页开关完全一致 |

### 4.2 QrTool 容错等级下拉框

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 类名 | `uuidtool__select`（未在 qr.astro 定义） | `qrtool__select`（已定义） |
| 渲染效果 | 浏览器默认 select 样式，边框/圆角/字号与同页其他表单不协调 | 13px 字号、`--radius-sm` 圆角、`--color-border` 边框，与同页颜色拾色器、文本输入框风格统一 |

| 过渡 | 无 | `border-color` 与 `box-shadow` 使用 `--transition-fast`（0.12s ease-out） |

## 六、风险评估

- **功能影响**：零。本轮仅修改 className 字符串与新增 CSS 规则，未触碰任何事件处理、状态管理、业务逻辑
- **兼容性**：新增样式全部基于 `global.css` 已有的设计令牌，浏览器兼容性与项目整体保持一致
- **回归风险**：极低。`qrtool__toggle` / `qrtool__select` 是新增规则，不会影响其他页面；QrTool 类名修复使元素从"无样式"变为"有样式"，不存在从一种样式变另一种样式的回归风险

## 七、后续建议

本轮为定向修复 + 审查。如需进一步优化，建议：

1. **统一 uuidtool / pwtool 的 select 交互态**：本轮在 `qrtool__select` 上增加了 `hover` / `focus-visible`，而 `uuidtool__select` 与 `pwtool__select` 仅有基础态，可后续统一补齐
2. **扩展扫描范围**：本次抽查了 13 个核心组件，项目共有 110+ 个工具组件，可分批继续核查
3. **focus-visible 全局策略**：可考虑在 `global.css` 中为 `select`、`input[type="text"]`、`textarea` 等表单元素定义统一的 `:focus-visible` 焦点环，避免每个工具页重复定义
