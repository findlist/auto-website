### P0 问题详细说明

**问题 1：ExifIFD / GPSIFD 指针解析失败**

修复前代码（`parseExifSegment`）：
```ts
const exifPointer = ifd0?.entries.find((e) => e.tag === TAG.ExifIfdPointer);
if (exifPointer && exifPointer.valueOffset !== null) {  // ← 永远为 false
  const exifOffset = tiffOffset + readU32(payload, exifPointer.valueOffset, bigEndian);
  exifIfd = parseIfd(payload, exifOffset, bigEndian, tiffOffset);
}
```

根因分析：
- `ExifIFDPointer` 是 EXIF 规范中的 LONG 类型（type=4），count=1
- `valueByteLength = 4 * 1 = 4`，等于 4 字节，按 EXIF 规范应**内联存储**在条目的 4 字节值字段中
- `parseIfd` 中 `vbl > 4` 判断为 false，走 else 分支，`valueOffset` 保持 `null`
- `parseExifSegment` 中 `exifPointer.valueOffset !== null` 条件永远不满足，子 IFD 解析被跳过

修复后代码：
```ts
if (exifPointer) {
  const ptrValue =
    exifPointer.valueOffset !== null
      ? readU32(payload, exifPointer.valueOffset, bigEndian)
      : readU32(payload, exifPointer.entryOffset + 8, bigEndian);  // 内联值回退
  const exifOffset = tiffOffset + ptrValue;
  exifIfd = parseIfd(payload, exifOffset, bigEndian, tiffOffset);
}
```
