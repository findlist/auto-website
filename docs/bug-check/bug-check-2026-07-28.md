## 记录的轻微问题（P2，未修复）

1. **UuidTool.tsx — 实时模式下"清空"后切换参数自动重新生成**
   `live=true` 时点击"清空"后 `items=[]`，切换 count/hyphen/upper 等参数会触发 useEffect → `regenerate()` 重新生成，与"清空"语义冲突。属设计权衡，非 bug。

2. **UuidTool.tsx / PasswordTool.tsx — setTimeout 未在组件卸载时清理**
   `flashNotice`、`handleCopyAll`、`handleCopyOne` 中的 `window.setTimeout` 未在 useEffect cleanup 中清理。React 18 会静默忽略卸载后的 setState，无功能影响。

3. **PasswordTool.tsx:183-188 — `regenerate` 中 `charsetEmpty` 分支为死代码**
   `charsetEmpty=true` 时"重新生成"按钮 `disabled`，此分支永远不会被触发。属防御性代码，可保留。

4. **PasswordHashTool.tsx:354-369 — `handleVerify` 提前 return 分支与 finally 重复 setLoading**
   提前 return 时显式 `setLoading(false)`，finally 又调用一次。React 批量化处理，无功能 bug，代码风格脆弱。

5. **PasswordHashTool.tsx:407-411 — 示例 hash 数据不真实**
   示例按钮加载的 bcrypt/pbkdf2 hash 与示例 password `correct horse battery staple` 不匹配，用户点击"验证密码"会得到"不匹配"。pbkdf2 示例的 hashBase64 解码后仅 16 字节，SHA-256 应为 32 字节。

6. **PasswordHashTool.tsx — 修改 password/hashInput 不会自动清除 error**
   用户看到 error 后修改输入，error 仍显示直到下次点击按钮才清除。可能误导。

7. **JweTool.tsx:362-368 — 生成测试 JWE 失败静默处理**
   生成失败仅 `console.error`，UI 无任何反馈（无 error 提示、无 notice）。

8. **JweTool.tsx — 修改 keyInput 后 decryptResult 不自动清除**
   解密失败后修改 keyInput，旧错误仍显示直到下次点击"解密"。

9. **jwe.ts:512-516 — `decryptJwe` 的 `_keyFormat` 参数声明但未使用**
   组件计算并传入 keyFormat，但 utils 函数体内根据 alg 自行判断格式，忽略此参数。API 契约不清晰。

10. **jwe.ts:553-556 — base64urlDecode 在 try 块之外**
    若 iv/ciphertext/tag 是非法 base64url，抛出 DOMException 不被 decryptJwe 内部 catch 捕获，错误信息不如内部友好化。

11. **jwe.ts:274-318 — `parseJwe` 不校验 iv/ciphertext/tag 的 base64url 合法性**
    parseJwe 只解析 protectedHeader，不校验其他段。用户粘贴的 JWE 可能 protectedHeader 合法但 iv 非法。

12. **QrTool.tsx — `live=true` 模式下"生成二维码"按钮 disabled**
    实时模式下按钮 disabled，生成失败时无法手动重试，必须先关闭实时模式。

13. **QrTool.tsx — generate async 竞态**
    generate 是 async 函数，参数变化时旧 generate 仍在执行，新 generate 开始。无 AbortController 取消机制。QRCode 操作较快，竞态概率低但存在。

14. **IfFunctionTool.tsx:357-360 — render 期访问 window 导致 hydration mismatch**
    `predictHitBranch` 在 useMemo 中调用，SSR 期间 `prefersDark=false`、`viewportWidth=1280`，CSR 读取实际值，导致 explainText 在 SSR/CSR 间不一致。影响范围有限（仅原理说明文本）。

15. **scripts/find-stale-tags.mjs:6 — 未使用的 `readFileSync` 导入**
    astro check hints。属脚本工具，非生产代码。

16. **src/utils/clipboard.ts:39 — `document.execCommand('copy')` 已弃用**
    建议后续迁移到 `navigator.clipboard.writeText`。当前作为兼容性降级路径保留，功能正常。
