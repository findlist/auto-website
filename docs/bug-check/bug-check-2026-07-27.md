## 记录的轻微问题（P2，未修复）

1. **jwe.ts:430-431 — ECDH-ES Concat KDF 忽略 apu / apv**
   `concatKdf` 将 `partyUInfo` / `partyVInfo` 硬编码为空 Uint8Array，未读取 Protected Header 中的 `apu` / `apv` 字段。对不携带 apu/apv 的 JWE（绝大多数场景）无影响；遇到携带这两个字段的 JWE 时派生密钥会与标准库不一致，导致解密失败。属标准互通性的边缘场景。

2. **jsonPath.ts:507+524 — 过滤表达式中 `@..foo` / `$..foo` 递归下降无法解析**
   `parseOperand` 解析 `@` / `$` 后续路径时循环条件未包含 `DOTDOT` token，导致过滤表达式内出现递归下降（如 `$..book[?(@..price > 10)]`）会报解析错误。过滤表达式内通常只用 `@.field`，影响面有限。

3. **jsonSchema.ts:89 — 不支持 `#` 形式的 $ref**
   `resolveRef` 只接受 `#/` 开头的引用，拒绝 `#` 单独使用（指向整个 schema 根，RFC 6901 合法语法）。遇到根引用的 schema 会报"无法解析 $ref：#"错误。

4. **jsonSchema.ts:239-248 — `uniqueItems` 对同一数组报告多次错误**
   检测到重复后 `break` 仅跳出内层循环，外层 `i` 继续扫描，对 `[1,1,1]` 会报告 2 次错误。不影响 `valid` 判定结果（仍为 false），仅错误列表有冗余条目。

5. **scripts/seo-audit.mjs:3-4 — 未使用的导入**
   `existsSync`、`normalize`、`sep` 从 node:fs / node:path 导入但未使用（astro check hints）。属脚本工具，非生产代码。

6. **src/utils/clipboard.ts:39 — `document.execCommand('copy')` 已弃用**
   API 标记为 deprecated，建议后续迁移到 `navigator.clipboard.writeText`。当前作为兼容性降级路径保留，功能正常。
